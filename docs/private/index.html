阿方智新隐私政策

发布日期：2026年10月16日
更新日期：2026年10月23日

阿方智新由武汉市朋成太科技有限公司（以下简称“我们”）提供，是面向 Android 设备的本地生活工具，提供生活计算、单位换算、购物比较、周期支出、生活计划、家庭用能和厨房备餐等功能。本政策适用于阿方智新应用、配套的在线隐私政策页面，以及您向我们提出的相关支持请求。

本政策说明我们处理信息的目的、方式、种类、保存方式与期限，以及您查阅、更正、删除信息和撤回同意的途径。请在使用前阅读，尤其关注加粗内容。仅阅读本政策，不表示您已经同意新增的信息处理活动。

无需注册账号。核心工具和方案管理在本机运行；计算记录、收藏、购物方案、周期账本及生活计划不会由本应用自动上传给我们。

本机保存也属于信息处理。您手动填写的日期、金额、成员昵称、地点、备注和费用，可能涉及您或他人的个人信息。应用不要求您填写真实姓名、手机号、身份证号、银行卡号或支付密码；请仅填写完成相应功能所需的内容。

备份和导出文件未额外加密；恢复备份会替换当前全部业务档案，不是合并。您主动复制、导出、分享或发送反馈时，所选内容会按您的操作交给对应的系统能力、文件服务或接收应用。

打开在线隐私政策需要联网，会产生加载网页所必需的网络请求信息；该请求不附带您的业务档案。您可在“我的—撤回隐私同意”中撤回，并选择是否删除本机业务档案和外观设置。

一、我们处理哪些信息，以及为什么处理

下列工具的输入来自您的手动填写、选择或您主动导入的备份。应用不会自动从通讯录、定位、电表、银行卡或其他应用中读取这些内容。是否使用某一工具、是否填写可选字段，由您决定；未填写必需字段时，仅该次计算或保存可能无法完成。

1. 基础计算、单位换算和历史记录

用于处理您输入或选择的表达式、数值、日期、单位和计算模式，生成计算结果。根据所用工具，输入可能涉及出生日期、日期区间、金额、数量、折扣、参与人数、距离、油耗、电价或几何尺寸。

普通计算工具成功计算后，会在本机保存工具类型、计算模式、原始输入、结果、记录时间和随机生成的本地记录编号，便于查阅和再次计算。连续相同工具、模式和输入可能合并为一条记录。单位换算的实时预览不写入历史；选择“计算并保存结果”后才形成记录。首页的灵感速算需主动选择“保存到计算记录”才写入历史。无效输入不会作为成功结果保存。

2. 购物比较与已保存购物方案

用于比较不同包装或折扣下的单位价、预计付款和余量。您主动保存时，应用在本机保存方案名称、需求数量及单位、预算，商品名称、包装价格、净含量、购买包数、折扣和优惠，以及方案编号和保存时间，用于重新打开、修改、比较和生成复盘。

这些内容是您提供的报价和需求，不代表已经购买、付款或实际节省的金额。应用不连接电商订单，也不提供购买、收款或支付服务。

3. 周期支出与账期状态

您主动保存周期账本时，应用在本机保存账本名称、预算、账本保存时间、账本与支出的本地编号，以及各项支出的名称、金额、分类、周期、每月使用次数、是否计入预算模拟、计划金额、首次付款日和用于推算账期的基准日期。您登记或撤销“已付”时，应用保存或移除对应账期的日期标记。

这些信息用于预算试算、展示待付或逾期账期、保存手动登记状态和生成复盘。已付状态来自您的手动确认，记录的是对应账期日期，并非真实扣款凭证、点击登记的时间或历史每次实际扣款金额。应用不读取银行流水，不自动扣费，不代为取消订阅，也不提供账期推送通知。

4. 生活计划、成员、安排、待办和费用

您创建或编辑生活计划时，应用在本机保存：

  • 计划名称、类型、手填地点、起止日期、预算、成员昵称，以及本地编号、创建时间和归档状态；
  • 时间安排的日期、时间、标题、地点、备注、预计金额和参与成员；
  • 待办标题、负责人和完成状态；
  • 费用名称、类别、金额、垫付成员、分摊成员，以及费用编号和登记时间。

这些内容用于组织旅行、聚会、搬家等生活安排，分配事项、汇总费用和生成线下对账建议。成员使用您手工填写的昵称，地点由您手工填写，应用不读取通讯录或获取定位，也不向成员自动发送邀请、任务或账单。对账建议不等于实际付款或转账。请在填写或分享涉及他人的信息前取得适当授权，避免填写无关的真实身份、家庭住址或其他敏感内容。

5. 家庭用能和厨房备餐

家庭用能看板处理您输入的电器名称、功率、使用时长、目标时长、天数和电价，用于本地费用估算；不会读取智能电表或真实电器数据。厨房备餐处理您输入的菜谱或餐次名称、原方份数、目标份数、食材名称、用量、单位、包装量和价格，用于份量缩放及采购估算。

这两个场景的输入及结果目前不加入已保存方案、计算历史或 JSON 备份。它们作为页面草稿供您查看、调整或主动复制。页面草稿可能在页面切换或系统恢复应用界面时保留，不能将其理解为离开页面后立即删除。

6. 方案库、待处理、统计和复盘

应用根据已有计算记录、购物方案、周期账本和生活计划，在本机进行搜索、筛选、待办状态更新和统计，生成您选择的一份方案的复盘。相关搜索词和筛选条件用于当前界面，不用于广告画像或跨应用追踪；生成报告不会自动上传或另建云端个人档案。

7. 收藏、外观、同意状态和页面草稿

应用在本机保存您收藏的工具和单位、深色或浅色等外观设置，以及是否已同意用户协议和隐私政策的状态，用于恢复使用偏好和执行启动流程。您可以取消收藏或修改外观。

未保存的方案输入、搜索条件、筛选状态及其他页面草稿可能保留在当前应用界面或由系统暂存以便恢复界面。未保存草稿不是已保存档案，不在 JSON 备份内，也不承诺能在卸载、更换设备或所有进程重启情况下恢复。记录、方案、成员和事项的随机编号仅用于在本机区分数据，不是设备标识符或用于跨应用识别您的账号。

二、备份、恢复、导出、复制与分享

1. JSON 备份包含什么

您在“我的—导出计算备份”中主动选择保存位置后，应用通过系统文件选择器导出本机业务档案，具体包含：

  • 计算历史的输入、结果、模式、时间和编号，以及工具收藏；
  • 已保存的购物方案及全部商品、需求和预算信息；
  • 已保存的周期账本、支出设置和手动登记的已付账期；
  • 生活计划及其成员昵称、时间安排、待办、费用、归档状态；
  • 单位收藏。

备份不包含外观设置、协议同意状态、未保存的页面草稿、家庭用能看板和厨房备餐页面输入。备份为可读取的 JSON 文本，未额外加密，可能包含日期、地点、成员昵称和费用等个人信息，请选择可信的保存位置并妥善保管。

2. 恢复会影响哪些数据

您在“我的—从备份恢复”选择文件后，应用读取您指定的文件，检查大小、格式及字段，并重新计算其中的基础计算结果。当前支持本应用第 1、2、3 版备份格式，导入文件和本机业务档案均受 2 MB（2,097,152 字节）上限约束。

确认恢复后，会用备份中的业务档案全量替换当前计算记录、工具收藏、购物方案、周期账本及已付账期、生活计划及关联内容、单位收藏，不会与当前内容合并。旧版备份不包含的新增数据列表会恢复为空，也会替换掉您当前已有的对应方案。建议先导出当前备份，再确认恢复。

取消文件选择或恢复确认，不会执行本次替换。恢复业务档案不会导入外观设置或协议同意状态。系统文件选择器只提供您选定文件或保存位置所需的访问能力，不代表授权应用扫描整个存储空间。

3. 计划清单导出与系统分享

生活计划可先预览清单，再复制文本或通过系统文件选择器导出 TXT、CSV。TXT 包含计划清单；CSV 为费用表，包含计划名称、地点、日期范围、费用、垫付人及分摊成员，不是整个档案的完整备份。导出内容以所选格式为准，均为未额外加密的可读取文本。

在计划清单中主动选择“选择其他应用分享”后，系统会显示接收应用选择器；您选择接收应用后，计划标题和清单文本会交给该应用，可能包含成员昵称、地点、安排、备注和费用。请在分享前核对内容和接收对象，并了解接收应用的后续发送、存储或同步规则。本应用不自行选择接收人，也不自动公开发布。

4. 复制和粘贴

您点击复制结果、采购清单、分析或复盘报告时，应用将对应文本写入系统剪贴板。基础计算工具中的“分享”目前为应用内预览和复制，与生活计划的系统分享功能不同。您主动使用系统粘贴功能时，相应内容会进入所选输入框；应用不在后台扫描剪贴板，不将剪贴板内容用于统计或上传。

如果您在系统文件选择器中选择云盘，文件将交给该文件服务；如果您复制或分享内容，副本将交给系统剪贴板或所选应用。这些副本不会因在本应用内删除记录、撤回同意或卸载而自动删除，需要您在对应位置单独处理。取消导出、复制或分享，不影响其他本地工具的使用。

三、在线政策阅读、意见反馈与支持

1. 在线隐私政策

您主动打开隐私政策时，应用通过 Android 系统 WebView 访问 https://privacy.studabloom.com/private/。您也可以使用浏览器访问该地址。为建立连接并返回页面，提供该网页的服务器会接收您的网络出口 IP 地址、请求路径、请求到达时间，以及浏览器或 WebView 随请求发送的类型、版本等请求头信息。这些信息用于完成网页访问、维持服务安全和排查访问故障。

政策页面请求不附带计算输入、历史记录、收藏、购物方案、周期账本、生活计划、成员昵称、反馈内容或应用生成的记录编号。该页面无需登录，页面本身不包含广告、用户行为统计脚本或用于追踪的 Cookie 设置逻辑，不据此建立广告画像。

必要网络请求会在您选择阅读页面时发生，包括首次同意提示中打开政策的情形。无法联网或证书验证失败时，在线政策可能无法加载，可检查网络后重试。用户协议是随安装包提供的本地页面，阅读无需联网；核心计算和已保存方案本身不依赖政策网页请求。

2. 意见反馈及联系支持

您在“我的—支持、关于与协议—意见反馈”中填写内容并选择打开邮件应用后，应用将反馈文字及固定邮件主题交给设备上的邮件应用，由您在邮件应用中确认发送。不会自动附加计算记录、方案、成员信息、设备标识符或诊断日志。

当您通过邮件或电话主动联系我们时，我们会接收您提供的反馈内容、发件邮箱或来电联系方式，以及您自行附加的材料，用于答复问题、处理请求和解决相关争议。请仅提供处理问题所必需的信息，避免发送密码、证件、金融账户或无关人员的资料。是否发送反馈由您决定，不提供反馈信息不影响本地功能。

四、设备权限与第三方组件

1. 权限及系统能力

  • 网络访问（INTERNET）：用于主动阅读在线隐私政策，具体网络信息见第三部分。应用不通过远程接口切换业务，不自动上传本机业务档案。
  • 用户选定文件的访问：备份、恢复和清单导出通过 Android 系统文件选择器处理，仅访问所选文件或保存位置，不要求读写外部存储或管理全部文件权限。取消选择只终止本次文件操作。
  • 当前不申请的权限：读写外部存储、管理全部文件、相机、麦克风、通讯录、定位、电话状态及运动信息。应用不采集照片、录音、通讯录、设备定位、IMEI 或计步数据，也不接入广告标识符采集。
  • 内部组件权限：安装包中的 AndroidX 签名级内部动态接收权限用于组件隔离，不是读取联系人、定位或设备信息的授权，无需您授予敏感权限。

您可在设备系统设置中查看应用权限及管理相关文件服务授权。系统输入法、系统文件选择器、剪贴板、邮件及接收分享的应用可能按各自功能使用权限，本应用不会代它们申请或获取这些权限。

2. 组件及外部服务

当前应用未接入用于广告投放、用户统计、推送、支付或社交登录的第三方 SDK。使用的主要组件及用途如下：

  • AndroidX／Jetpack、Jetpack Compose（Android／Google 开源组件）：实现界面、导航、应用状态管理和运行性能支持，在本应用中不用于向组件提供方发送您的业务档案或设备标识符。
  • Gson（Google 开源组件）：在本机处理 JSON 档案与备份，不通过该组件联网传输业务档案。
  • Android 系统 WebView：显示协议与隐私政策，在线页面涉及的网络请求见第三部分。应用内协议页面不开启 JavaScript、文件访问或混合 HTTP 内容。
  • 系统输入法、剪贴板、文件选择器及您选择的文件服务、邮件或分享接收应用：仅在您使用相应输入、复制、文件操作、反馈或分享功能时，按您的操作接收相关内容。提供方取决于您的设备和选择，其独立处理行为请同时查看该服务的说明。

我们不会以第三方规则替代自身应履行的信息保护义务。应用内计算和方案功能不要求注册这些外部服务账号；您选择的外部服务可能自行要求联网或登录。

五、信息存放在哪里，保存多久

1. 本机业务档案与设置

业务档案、收藏、外观和同意状态保存在当前设备的应用私有存储中，应用不提供账号云同步，也不能通过后台读取或恢复仅保存在您设备上的这些内容。应用自身不会主动将本机档案传输至境外；设备厂商的备份、迁移能力和您选择的云盘或分享服务可能另行处理副本，请同时管理相关系统设置及服务。

  • 计算历史最多保留最近 200 条，新增记录超过上限时移除较早记录，您可提前删除。
  • 已保存购物方案、周期账本和生活计划，保留至您删除、通过备份恢复将其替换，或清除相应本机数据。当前每类最多 30 份；达到数量或档案大小上限时会提示处理，不按“使用不活跃”自动删除这些方案。
  • 周期账本的已付标记保留至您撤销、删除相应支出或账本，或替换／清除档案；每项支出最多保存 600 个已付账期。
  • 收藏保留至您取消收藏、恢复替换或清除相应数据；外观设置保留至您修改或删除；同意状态在撤回后改为未同意，系统清除应用数据后移除。

归档生活计划只是改变展示和处理状态，不等于删除。未保存草稿及系统界面恢复状态不属于上述长期保存档案；如需清除设备上的应用数据，可使用系统的应用存储管理。

2. 导出、分享及支持请求

您导出的文件、复制的文本和主动分享的副本由对应位置或接收服务保存，本应用不能统一控制其期限。您主动发给我们的支持请求及联系方式，仅在答复、处理问题和解决相关争议所必需的最短期间保留，目的实现后删除或匿名化；法律法规要求保留的，按其规定执行，保留期间仅开展必要的存储和安全保护处理。

政策网页访问所需的请求信息用于完成访问；如因必要的服务安全、故障排查或法定义务留存访问日志，保留范围和期限限于相应目的所需的最小范围与最短期限，目的结束后删除或匿名化，法律法规另有要求的从其规定。您可通过文末联系方式咨询相应信息或提出权利请求。

六、查阅、更正、删除与撤回同意

1. 查阅、复制和更正

  • 在“记录”查看计算历史，打开原工具调整输入后再次计算。新的计算不会自动删除您不再需要的旧记录，可单独删除旧记录。
  • 从首页“我的生活方案”或对应场景进入购物方案、周期账本、生活计划，查看或修改已保存内容。在相应页面保存修改，或登记／撤销账期状态、更新待办。
  • 通过结果、清单或复盘页面复制相应文本；通过“我的—导出计算备份”取得完整业务档案副本。收藏可在相应星标入口取消，外观可在“我的”中调整。

2. 删除与清空的区别

  • 删除计算历史：可在“记录”逐条删除，或在“我的—清空计算记录”清空历史。该操作不会删除工具收藏、单位收藏、购物方案、周期账本、生活计划或外观设置。
  • 删除购物方案：在购物场景的方案库删除已保存方案。当前已打开的编辑草稿可能继续保留，需另行新建或清空草稿；删除已保存方案不等于自动清除当前草稿。
  • 删除周期账本：在周期账本的已保存方案列表删除整本账本，同时删除其中的付款标记；如移除账本内单项支出，需要保存修改后生效。
  • 删除生活计划：在生活计划中删除整份计划或其中的安排、待办、费用。归档仍会保留数据，如需删除应选择删除操作。
  • 清除应用数据：可在设备系统设置的本应用存储管理中清除应用数据，或卸载应用。操作前请导出需保留内容；我们不能从后台恢复仅在您设备上保存的档案。

3. 在应用内撤回隐私同意

入口为“我的—撤回隐私同意”。确认后会撤销本机同意状态并退出应用；下次打开会重新展示用户协议与隐私政策，您可阅读后重新决定是否同意。

  • 默认不勾选删除：保留计算记录、工具收藏、单位收藏、购物方案、周期账本及付款标记、生活计划及关联内容、外观设置。撤回后退出，不再继续新的业务处理；以后再次同意，可继续使用仍保留的本机档案。
  • 勾选同时删除本机数据：会删除上述全部业务档案和外观设置，同时将同意状态设为未同意。包括购物方案、周期账本、生活计划中的成员、安排、待办和费用。此删除无法在本机直接撤销，请先取消操作并导出需要保留的备份。

撤回或删除不会自动清理已导出的备份、TXT／CSV 文件、系统剪贴板、已发送邮件或其他应用收到的副本，也不等于清除设备上所有系统 WebView 数据。请在对应位置另行管理。撤回不影响撤回前已经依法开展的处理。

首次提示中，您可先阅读协议和政策，再选择“同意并继续”或“不同意”；选择“不同意”会退出当前应用。您可随时停止使用备份、复制、分享或反馈等可选功能，取消这些操作不影响其他本地工具。

七、共享、转让、公开披露与安全保护

本机档案采用 Android 应用私有存储隔离；备份导入时校验大小、格式和字段；在线政策通过 HTTPS 加载，证书异常时停止连接。应用私有存储不等于额外加密，JSON、TXT、CSV 等导出文本也未额外加密。请保护设备锁屏、邮箱和文件服务账号，谨慎分享涉及个人情况的文本。

对于我们收到的支持请求，限定访问范围，仅用于处理相关问题。发生或可能发生个人信息安全事件时，我们将及时采取补救措施，并按适用法律履行报告、通知及其他义务。

未成年人应在监护人指导下阅读本政策和使用应用。本应用不提供专门面向儿童的账号或社交服务，也不要求提供儿童真实身份信息。请勿在成员昵称、地点、备注或反馈中填写与功能、问题无关的未成年人个人信息。
