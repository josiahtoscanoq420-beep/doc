阿方智新隐私政策

发布日期：2026年10月16日
更新日期：2026年10月21日

阿方智新由武汉市朋成太科技有限公司（以下简称“我们”）提供，是面向 Android 设备的生活计算工具箱，提供日常计算、单位换算、日期间隔与推算、年龄计算、折扣计算、账单分摊、单价对比、油费与用电估算、面积周长、百分比及金额大写等功能。本政策适用于阿方智新应用及您向我们提出的相关支持请求。

我们重视您的个人信息保护。本政策说明应用处理哪些信息、处理目的与方式、保存期限，以及您管理和删除信息的途径。请在使用前阅读，尤其注意加粗内容。

核心说明：应用无需注册账号，计算功能可离线使用。计算输入、结果、历史记录、收藏和外观设置在本机处理、保存，应用不会自动将这些内容上传给我们。仅当您主动导出、复制或通过邮件反馈时，相关内容才会按您的操作交给所选文件服务、系统剪贴板或邮件应用。

一、我们处理的信息及用途

1. 计算输入与结果

您使用工具时，应用会在本机处理您输入或选择的表达式、数值、日期、单位、计算模式等内容，用于完成相应计算和显示结果。日期、金额等输入可能涉及您的个人情况，是否输入及输入什么内容由您决定；应用不要求您提供姓名、手机号、身份证号或金融账户信息。

成功计算后，应用会自动在本机保存工具类型、计算模式、原始输入、结果、记录时间和随机生成的记录编号，供您查阅及再次计算。记录编号用于区分计算记录，不是设备标识符。普通页面切换时，输入草稿也可能保留在当前应用界面状态中，以便继续操作。

2. 收藏、设置与同意状态

应用在本机保存您收藏的工具、选择的深色或浅色等外观设置，以及您是否已同意用户协议与隐私政策的状态，用于恢复使用偏好和执行启动流程。这些信息不会用于广告画像、商业推荐或跨应用追踪。

3. 备份导出与恢复

您主动选择“导出计算备份”后，应用通过系统文件选择器，将计算记录和工具收藏写入您指定位置的 JSON 文件；您选择“从备份恢复”后，应用仅读取您指定的备份文件，检查格式和内容，并在您确认后替换当前计算记录与收藏。

备份文件包含计算输入、结果和时间等记录，采用可读取的文本格式，未额外加密。请妥善选择保存位置，不向无关人员提供备份。若您选择云盘或其他文件服务，文件会按您的选择交由该服务处理，具体存储和同步行为受该服务的规则约束。取消导入或导出不影响其他计算功能。

4. 复制、粘贴与分享

您点击“复制结果”或“复制分享内容”时，应用会把所选结果文本写入系统剪贴板。“分享”功能在应用内展示文本预览，由您决定是否复制；应用不会自动把计算结果发送给他人。您主动使用系统粘贴功能时，相应文本会进入您选择的输入框。应用不在后台扫描剪贴板，也不将剪贴板内容用于统计或上传。

复制后的内容由系统剪贴板管理，其他获得系统允许的应用可能读取该内容；如不希望继续保留，请使用系统提供的方式清理或覆盖。

5. 意见反馈与联系支持

您在“意见反馈”中输入内容并选择打开邮件应用后，应用会将反馈文字及固定的邮件主题交给您设备上的邮件应用，由您在邮件应用内确认发送。应用不会自动附加计算历史、设备标识符、通讯录或诊断日志。

当您通过邮件或电话主动联系我们时，我们会接收您提供的反馈内容、发件邮箱或来电联系方式，以及您自行附加的材料，用于答复问题、处理请求和解决争议。请仅提供处理问题所必需的信息，避免发送密码、身份证件、金融账户或无关人员的信息。您不提供反馈信息，不影响计算功能的使用。

二、设备权限与网络访问

我们按实际功能使用系统能力，不因应用声明某项权限就当然读取相关信息。当前版本的权限及使用情况如下：

  • 网络访问（INTERNET）：当前安装包保留网络权限声明；现有启动流程直接加载本地工具箱，核心计算及应用内本地政策阅读不需要联网，应用不通过远程接口切换业务，也不自动上传计算记录、收藏或设备标识符。您选择的邮件应用、文件服务或浏览器可按各自功能联网。
  • 读写外部存储（READ_EXTERNAL_STORAGE、WRITE_EXTERNAL_STORAGE）：当前安装包仍声明这两项权限，但现有生活计算功能不主动申请或使用它们，不扫描共享存储中的照片或其他文件。备份导入、导出使用系统文件选择器，仅访问您选定的文件或位置。
  • 相机、麦克风、通讯录、位置、电话状态及运动信息：当前生活计算功能不申请这些权限，不采集照片、录音、联系人、定位、设备 IMEI 或计步数据。

您可在设备的系统设置中查看应用权限和管理文件服务授权。不同系统的设置名称可能不同，取消某次文件操作或相关文件访问授权只影响对应的备份操作。

三、第三方组件及服务

当前版本未接入用于广告投放、用户统计、推送、支付或社交登录的第三方 SDK，也未接入友盟统计和腾讯 X5 浏览器 SDK。

应用使用 AndroidX／Jetpack 等组件实现界面、导航和本地状态管理，使用 Gson 处理本地 JSON 数据。这些组件在本应用中用于上述本地功能，不被用于向其提供方发送计算记录或设备标识符。应用内政策页面使用 Android 系统 WebView 显示随安装包提供的本地 HTML 文本。

系统输入法、剪贴板、文件选择器、您选定的文件提供方及邮件应用，由设备系统或相应服务提供方提供。只有在您主动使用对应功能时，相关内容才会按您的操作交给对应系统能力或服务；其独立处理行为请同时参阅相应服务的隐私说明。我们不会以第三方服务规则替代自身应履行的个人信息保护义务。

四、信息的存储与保存期限

本地数据：计算记录、收藏、外观及同意状态保存在当前设备的应用私有存储中。当前工具箱最多保留最近 200 条计算记录，新增记录超过上限时移除较早记录。您可以提前删除记录或清除应用数据；收藏和设置保留至您修改、取消收藏或清除应用数据。

我们不提供应用内账号云同步，也不能通过后台读取或恢复您仅存于本机的计算记录。应用自身不主动将这些本地内容传输至境外。设备厂商的备份、迁移功能，以及您主动选择的云盘等服务，可能按您的系统设置处理副本，请同时管理相关设置。

导出及复制的内容：已导出的备份、剪贴板内容和您自行发送的副本，不会因应用内删除记录、清除数据或卸载而自动全部删除，需要您在相应位置分别处理。

支持请求：您主动发送给我们的反馈及联系方式，仅在答复、处理问题和解决相关争议所必需的最短期间内保留，目的实现后删除或匿名化处理；法律法规要求保留的，按其规定执行，保留期间仅开展必要的存储和安全保护处理。

五、共享、转让与公开披露

我们不会出售您的个人信息，不会将您的计算记录用于广告投放或用户画像。应用不会自动向第三方发送您本机的计算记录。您主动导出文件、复制内容或发送邮件时，相关接收范围由您的操作决定，具体情况见本政策第一、三部分。

如确需委托其他服务商处理我们收到的支持请求信息，我们将限定处理目的、期限和范围，要求其采取必要保护措施并履行监督责任。向其他独立的信息处理者提供信息时，我们会依法告知接收方、处理目的、方式和信息种类，并在法律要求时取得单独同意。

因合并、分立或其他原因确需转移个人信息的，我们将依法告知接收方名称和联系方式，要求接收方继续履行保护义务。我们不会公开披露您的个人信息，除非取得适用的有效同意或依法必须披露；依法披露时仅提供必要范围的信息。

六、信息安全保护

本地记录使用 Android 应用私有存储隔离，导入备份时检查文件大小、格式和字段，并重新计算导入结果，以降低异常文件影响。我们不在应用中部署自动采集设备标识、行为轨迹或后台上传诊断信息的功能。

对于您主动提供给我们的支持请求信息，我们将限定访问范围，仅用于处理相关问题，并采取与信息风险相适应的保护措施。请同时保护设备锁屏、邮箱及文件服务账号，谨慎分享包含个人情况的计算结果或备份。导出文件为明文文本，应用私有存储也不等同于对所有内容进行额外加密。

发生或可能发生个人信息安全事件时，我们将及时采取补救措施，并根据适用法律履行报告和通知义务。

七、您如何管理自己的信息

  • 查阅与复制：在“记录”中查看计算历史，复制结果，或在“我的”中导出计算备份。
  • 更正：从历史记录打开工具后调整输入并重新计算；如不需要原记录，可单独删除。收藏和外观设置可随时调整。
  • 删除：可在“记录”中逐条删除，或在“我的”中选择“清空计算记录”。清空记录会保留收藏和外观设置；取消收藏需分别操作。
  • 清除全部本地数据或停止使用：可通过设备系统设置中的本应用存储管理清除应用数据，或卸载应用。清除数据会同时移除本地记录、收藏、设置及同意状态；如重新使用，应用会重新展示首次同意流程。此前导出的文件及其他服务中的副本需单独删除。
  • 撤回同意或限制处理：您可停止使用复制、备份或反馈等可选功能，在系统中管理相应权限或文件授权，并按上述方式清理本地数据。对您已主动发送给我们的信息，可通过第十部分联系方式提出撤回同意、限制处理或删除请求。撤回不影响撤回前已依法开展的处理。
  • 账号注销：本应用不提供注册或登录账号，因此没有需要注销的应用账号；本地数据按上述方式管理。

您也可联系我们，依法请求查阅、复制、更正、补充、删除相关个人信息，或要求解释本政策。对于仅在您设备上保存的数据，我们会提供操作指引，不会要求您为了删除本地数据而先上传全部记录。处理支持请求时，我们仅核实必要信息，并在一般情况下于 10 个工作日内答复；无法满足请求时会说明理由和可用的申诉途径。如对处理结果有异议，您可向有关主管部门投诉，或依法通过诉讼等途径维护权益。

八、未成年人保护

未成年人应在监护人的指导下阅读本政策和使用应用。本应用不提供专门面向儿童的账号、社交或信息采集服务。请勿通过意见反馈发送与问题无关的未成年人个人信息；如支持请求确需涉及不满 14 周岁儿童的个人信息，应由监护人联系我们，我们将依法核实监护人同意，并仅在处理该请求的必要范围内使用和保护相关信息。

如发现未经监护人有效同意收到不满 14 周岁儿童的个人信息，我们将及时核实并删除或采取其他法律要求的保护措施。监护人可通过第十部分联系方式请求协助处理。

九、本政策的更新

我们会根据实际功能和信息处理方式的变化更新本政策，并标注更新日期。您可在应用“我的—支持、关于与协议”中查看隐私政策。涉及处理目的、方式、信息种类或接收方等重要变化时，我们会在实施前依法告知；需要重新取得同意或单独同意的，将依法完成后再开展相应处理。

仅更新网页或本政策文字，不代表您已经同意新增的信息处理活动。我们不会以静默更新政策或将继续使用一概视为同意的方式，替代法律要求的告知和授权。
